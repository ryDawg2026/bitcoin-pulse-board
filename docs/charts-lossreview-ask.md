# Price charts, loss post-mortems and Ask AI

**Price chart** (`charts.js`): 1m / 5m / 15m candles (green up, red down) from Coinbase BTC-USD (fallbacks Binance market-data host, Kraken), the current window's Kalshi strike (amber dashed; consensus open if Kalshi is down), 15-minute window boundaries, earlier windows' strikes as small amber ticks, volume, hover/touch readout. Refreshes every 15 s / 30 s / 45 s.

**Signal strips** (last 3 h, only real samples): large-trade flow by tier ($25–100k / $100k–1M / $1M+, taker buys vs sells) and liquidations (from the flow tracker, only while the page is open); Kalshi order-book imbalance (sampled by the context box); BRTI settlement gap (sampled here ~20 s); OKX funding history (real, public endpoint); OKX open interest (sampled ~60 s — OKX's history endpoint has no browser CORS access, so nothing is back-filled).

**Grokky reasoning:** one new, labelled *reading* — the last 10 minutes' move versus the typical 10-minute move from real 1-minute closes (only when |z| ≥ 1.5; a mean-reversion reading in line with the v2 engine; earlier backtests found only a small edge). Funding, liquidations, flows, order book, BRTI gap and Fear & Greed were already cited. Each frozen rationale now also stores the full list of readings (direction + text) and the typical 15-minute move.

**Loss post-mortem** (`grokky.js`, card "Why a pick lost"): every round has one loser. In first person it states what the loser picked and at what probability, final settlement vs strike with move size and ratio to a typical 15-minute move, (when 1-minute candles covering the window were loaded) the in-window path, which cited readings were wrong, and which opposing readings turned out right. Records created before this feature, or windows the page didn't cover, say what wasn't stored instead of guessing. Click any scoreboard row to read that round. An example render exists only via `GrokkyPanel.showDemo(true)` (used for screenshots; labelled EXAMPLE).

**Ask AI** (`ask.js`): built-in mode (live board data + fixed FAQ, advice questions declined) is the default. AI mode activates only when `window.ASK_AI_URL` points at the `pulse-ask-ai` Worker (see `tools/ask-ai-worker/DEPLOY.md`); every answer is labelled with its source, and any failure falls back to a labelled built-in answer. The page sends only `{question, compact board snapshot, last 6 chat turns}` — never the play-money balance, bets or storage.
